How it works (simple)

  1. Click Start. Allow camera and microphone.
  2. Speak your answer. The page shows live transcript using browser speech API.
  3. Click Analyze & Save — results are stored on server and you get suggestions.

Server stores only simple scores for demo (no personal text). For production, add authentication and secure storage.
